# Chapter One V10.8 — Release notes

- Dedicated free Amharic routing: Gemini 3.8 Flash Free Tier primary, explicit OpenRouter Gemma 4 26B `:free` fallback.
- Hard stop: Amharic never routes to OpenAI or another paid provider.
- English/Arabic/other non-Amharic routes preserve existing OpenAI integration.
- Supabase session validation now protects all AI POST requests before provider keys can be used.
- Genre is passed to outline and each chapter generation/continuation. Fiction and nonfiction have different content constraints.
- Four local Canvas cover options; no AI image API calls. Legacy paid covers function remains disabled.
- Translator supports searchable PDF, DOCX, TXT and MD. Scanned PDF OCR is not included.
- Existing Supabase auth, book sync schema, local storage, reader and PWA preserved.

## Verification

Only syntax and mocked provider/auth tests were run. No live Gemini, OpenRouter or OpenAI request was sent; no live Amharic writing quality claim is made. No GitHub push or Netlify deploy was performed by this build.
